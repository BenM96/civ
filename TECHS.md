# Technologies

_Generated by `tools/generate_tech_doc.gd` from the tech files in `scripts/techs/tier_N/` - don't edit by hand; run the script again instead._

Techs are researched with Electrum from **Research (R)**. Each game deals every tech out to 3 trees, 2 per tree from each tier, tier 1 first; which tree a tech lands on is shuffled per game (the same for every colony). A tree is researched in order, and the Nth tech on a tree costs N Electrum, so each tier's heading below shows what its techs cost. Researching a tech only unlocks or raises things - it never builds anything.
